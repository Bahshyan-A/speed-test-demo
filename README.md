# Измерение скорости скачивания

Требуется Node.js 18 или новее. Все зависимости встроены в Node.js.

Из каталога со скриптом выполните команду, подставив HTTP- или HTTPS-адрес файла.

```sh
node download.mjs "https://example.org/image.jpg"
```

Скрипт отправляет 10 последовательных GET-запросов. Каждый следующий запрос начинается после полного чтения предыдущего ответа. При ошибке скрипт выводит сообщение и завершается с ненулевым кодом.

После успешной загрузки скрипт выводит три показателя.

- Среднее время запроса в секундах, от отправки запроса до полного чтения ответа.
- Общий объём прочитанных тел ответов в байтах.
- Скорость скачивания в МиБ/с, равную общему объёму в мебибайтах, делённому на суммарное время запросов в секундах. Один мебибайт равен 1 048 576 байтам.
В терминале полоска показывает число завершённых запросов, а подпись — номер текущего. При перенаправлении вывода в файл сохраняется обычный текст.
